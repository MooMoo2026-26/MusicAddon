# 🎵 MusicAddon

Custom Minecraft Bedrock music addon for custom songs, discs, and sound events.

## ✨ Features

- Custom music support
- Custom sound events
- Custom music discs
- Bedrock Edition compatible
- Easy to expand
- Lightweight setup
